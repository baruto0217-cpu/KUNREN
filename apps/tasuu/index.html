集団災害対応
フレームワーク

CSCATTT（医療指揮・調整）と METHANE（初期報告）は、英国のMIMMS（大事故災害への医療対応）に由来し、日本でもDMATや消防の教育で使われる枠組みです。本アプリは現場での参照と報告作成を助けます。地域の要綱・プロトコールがある場合は、そちらを優先してください。

CSCATTT

C
Command & Control — 指揮統制
明確なリーダーシップと指揮系統の確立

集団災害対応において最初に行うべきことは、明確な指揮命令系統の確立です。誰が現場の医療指揮を取るかを明確にし、全員がその指示に従う体制を作ります。

  • 消防の現場指揮（指揮隊）と、医療の指揮・調整（DMATなど）を区別して確認
  • DMAT・救急隊・消防・警察との指揮系統の調整
  • 指揮所（Command Post）の設置場所の決定
  • 役割と責任の明確な割り当て
  • 定期的な状況報告の仕組みの確立
S
Safety — 安全
3Sの原則：自己・現場・傷病者

安全確保は「自己（Self）→ 現場（Scene）→ 傷病者（Survivor）」の優先順位で行います。救助者自身が二次被害を受けることで、全体の対応能力が低下します。

  • Self：個人防護具（PPE）の着用確認
  • Scene：危険物・倒壊リスク・火災・ガス漏れの確認
  • Survivor：傷病者の安全な場所への移動
  • ホットゾーン・ウォームゾーン・コールドゾーンの設定
  • 安全ルートの確保と定期的な安全評価
ホットゾーン ウォームゾーン コールドゾーン
C
Communication — 情報伝達
効果的なコミュニケーション体制の確立

METHANEによる標準化された初期報告から始まり、継続的な情報共有体制を構築します。通信手段の確保と情報の正確な伝達が重要です。

  • METHANEによる初期報告の実施
  • 無線・衛星電話等の通信手段の確保
  • 病院・DMAT・消防・警察との情報共有
  • メディア対応窓口の一元化
A
Assessment — 評価
継続的な状況・資源評価

現場の状況は常に変化します。傷病者数・重症度の変動、利用可能な資源、病院の受け入れ能力などを継続的に評価し、対応を柔軟に調整します。

  • 傷病者数と重症度分布の把握・更新
  • 現場での医療資源（人員・資器材・薬品）の評価
  • 近隣病院の受け入れ可能数の確認
  • 追加支援の必要性の判断
  • 状況の悪化・好転の継続的モニタリング
T
Triage — トリアージ
START法・JumpSTARTによる重症度分類

最大多数の最大利益（Greatest Good for the Greatest Number）の原則に基づき、限られた資源を最も効果的に配分するための重症度分類を行います。

  • 赤（I）：生命危機あり、直ちに治療が必要
  • 黄（II）：重傷だが待機可能
  • 緑（III）：軽傷、独歩可能
  • 黒（0）：死亡、または現状では救命困難（生存者は再評価の対象）
  • START法（30秒/人）による迅速なトリアージ
  • 状況変化に応じた再トリアージの実施
T
Treatment — 治療
優先度に応じた医療処置の提供

トリアージ区分に従い、治療エリアを設置して優先度の高い傷病者から処置を行います。現場での処置は生命維持に必要な最低限を行い、速やかに搬送します。

  • 治療エリア（赤・黄・緑・黒）の設置
  • 致死的な大出血の止血を最優先し、気道・呼吸・循環の順に対応。保温（低体温の予防）も並行
  • 救急隊は救急救命処置の範囲内で処置し、医師が行う治療（薬剤など）とは分けて考える
  • 医薬品・資器材の効率的配分
  • DMATや専門医チームとの連携
T
Transport — 搬送
適切な医療機関への効率的搬送

傷病者を適切な医療機関へ安全かつ迅速に搬送します。各病院の受け入れ能力を把握し、負荷が特定の病院に集中しないよう分散搬送を図ります。

  • 搬送順位の決定（トリアージ区分に基づく）
  • 救急車・ドクターヘリなど搬送手段の効率的な運用
  • 搬送先病院との事前調整・受け入れ確認
  • 分散搬送による特定病院への過負荷防止
  • 搬送記録（誰が・いつ・どこへ）の管理

METHANE

M
My call sign / Major incident — 名乗りと宣言
「こちらは〇〇です」から始め、大事故災害かどうかを伝える

報告の最初に自分のコールサイン・役職・所属を明確に述べます。受信側が誰からの報告かを即座に把握できることが重要です。

あわせて「大事故災害（多数傷病者事故）の待機（スタンバイ）」または「発生（宣言）」を伝えます。言葉は地域の計画に合わせます。教材によってMを「My call sign」とするものと「Major incident」とするものがあります。

例：「こちらは〇〇救急隊、田中隊長です。多数傷病者事故の発生を宣言します」

E
Exact location — 正確な位置
GPSや住所で特定できる情報を

現場の正確な位置を報告します。住所、交差点名、ランドマーク、GPS座標など、受信者が地図上で特定できる情報を伝えます。

例：「場所は〇〇市〇〇町1-2-3、〇〇駅南口前の広場です」

T
Type of incident — 事案の種類
何が起きているかを簡潔に

事案の種類と規模を報告します。交通事故・火災・爆発・建物崩壊・化学物質漏洩など、対応方針に影響する情報を簡潔に伝えます。

例：「大型バスと列車の衝突事故です」

H
Hazards — 危険因子
現在と潜在的なリスク

現在存在する危険と潜在的な危険の両方を報告します。これにより、支援隊員が適切なPPEや対応機材を準備できます。

  • 火災・爆発リスク
  • 化学物質・CBRN（化学・生物・放射線・核）汚染
  • 建物崩壊・土砂崩れリスク
  • 交通による二次事故リスク
  • 「現在なし」も明示的に報告
A
Access — アクセス
最適な進入・退出ルート

支援隊員・資器材・救急車がどこから現場に入れるかを報告します。渋滞・通行止め・最適なルートを具体的に伝えます。

例：「北側の〇〇通りから進入可能、南側は通行止めです。救急車の待機場所は〇〇公園駐車場です」

N
Number of casualties — 傷病者数
重症度別の概数を報告

傷病者の総数と重症度別の概数を報告します。初期段階では概数で構いませんが、更新を続けます。

  • 赤（重症）：〇名
  • 黄（中等症）：〇名
  • 緑（軽症）：〇名
  • 黒（死亡/救命不能）：〇名
  • 要救助者（閉じ込め等）：〇名
E
Emergency services — 緊急対応機関
必要な支援と現在の対応状況

現在現場にいる機関と追加で必要な資源・機関を報告します。DMATの要請、特殊車両の必要性なども含めます。

  • 現在対応中の機関（救急・消防・警察）の状況
  • 追加要請が必要な機関・資源
  • DMATの要請の要否
  • ドクターヘリの要請の要否
  • 特殊資器材（除染・化学・重機）の必要性

START 法フロー

① 歩けるか？

「歩ける人はこちらへ」と呼びかける
歩ける → 緑
歩けない → ②へ

② 呼吸はあるか？

なし → 気道確保
　気道確保でも呼吸なし → 黒
　気道確保で呼吸が戻った → 赤
あり → ③へ

③ 呼吸数は？

9回/分以下 または 30回/分以上 → 赤
10〜29回/分 → ④へ

④ 循環は？

橈骨動脈を触れない または CRT 2秒超 → 赤
触れる → ⑤へ
CRTは寒い場所では不正確。境界（2秒以上／2秒超）は地域の基準で確認

⑤ 意識は？

簡単な指示に従えない → 赤
従える → 黄

国内で広く使われている修正START法です（原法は呼吸数30回超のみ）。地域の基準と照らし合わせてください。

PAT法

🔍
PAT法（生理学的・解剖学的評価）＝二次トリアージの方法のひとつ
一次トリアージで分けた傷病者を、救護所などで詳しく評価し、処置と搬送の順番を決める。緑も状態が変われば対象。
🔄
二次トリアージのポイント
STARTは1人30秒が目安の一次評価。PATで詳しく評価し、タグを随時更新する。
📌 一次 vs 二次の違い
一次トリアージ（START）
1人30秒が目安。歩行・呼吸・循環・意識で手早く分ける。資源配分の大枠を決める。
二次トリアージ（PAT）
詳細評価。処置しながら再評価。搬送先・処置内容を決定する。
  • 一次で緑タグでも症状悪化 → 直ちに再評価・タグ変更
  • 一次で黒タグでも資源余裕があれば再評価を検討
  • 処置後に必ずバイタルサインを再確認
🔁 再トリアージのタイミング
  • 処置（止血・気道確保）後
  • 搬送前（状態が変わっていないか）
  • 待機中も定期的に（赤は特に短い間隔で。間隔は状態と資源で決める）
  • 患者自身が「悪化した」と訴えたとき
  • 救助者が異変に気づいたとき（呼吸変化・意識変化）
📝 タグ記録の注意点
  • 区分を変えたときの付け替え方は、使っているタグの正式な手順に従う（前の評価と時刻が分かるように残す）
  • 記録：評価者名・評価時刻・変更理由を記入
  • 行った処置（薬剤を含む）と時刻をタグに記載

CBRNE 対応

⚠ CBRNE 基本原則
近づかない・触らない・吸わない
通常のMCI対応に加え、汚染拡大防止と救助者の二次汚染防止が最優先事項。防護していない隊員は危険区域に入らない。救助は、防護・訓練・測定のできる専門の隊が指揮のもとで行う。
C
Chemical — 化学剤
神経剤（サリン・VX）・びらん剤（マスタード）・窒息剤（塩素）・血液剤（青酸）
🔍 識別・症状
  • 神経剤：縮瞳・鼻汁や流涎などの分泌増加・気管支の収縮と呼吸困難・筋線維束攣縮・けいれん・意識障害
  • びらん剤：皮膚水疱・眼痛・遅発性（数時間後に出現）
  • 窒息剤：咳・チアノーゼ・肺水腫（塩素特有の刺激臭）
  • 血液剤（青酸）：頭痛・けいれん・急速な意識消失
  • 臭いで確かめるために近づかない（臭いを感じない人も多い）
  • 危険物の標識（黄色い「危」・国連番号）やイエローカードを、安全な位置から確認
🚨 対応手順
  • 防護していない隊員は近づかない（救助は専門の隊）
  • 風上・高台への避難誘導（風下は汚染リスク大）
  • 除染：まず脱衣と拭き取り。水での除染は物質と付着の状態に応じて行う
  • 重症者は最低限の除染（脱衣など）で搬送する場合がある。搬送先へ原因物質と除染の状況を事前に連絡
💊 医療機関などで行う治療（参考）
  • 神経剤：アトロピン（繰り返し投与）＋ PAM（プラリドキシム）
  • 青酸系血液剤：ヒドロキソコバラミン（シアノキット）
  • 窒息剤：酸素投与・安静（遅れて肺水腫が出ることがある）
  • 救急隊は、防護と除染をしたうえで、救急救命処置の範囲内の処置を行う
B
Biological — 生物剤
炭疽菌・天然痘・ペスト・ボツリヌス毒素・ウイルス性出血熱
🔍 特徴・識別
  • 化学剤と違い潜伏期間あり（数時間〜数週間）
  • 多数者の同時・類似症状発症が手がかり
  • 感染経路：接触感染・飛沫感染・空気感染（種類による）
  • 炭疽菌：皮膚型（黒色痂皮）・肺炎型（高致死率）
  • 天然痘：顔と手足に多い発疹（手のひら・足の裏にも）。同じ部位の発疹は同じ時期のものがそろう
🚨 対応手順
  • 感染経路に応じた防護：N95マスク・ゴーグル・ガウン・手袋
  • 原則として個別に隔離。同じ病原体の患者をまとめる（コホーティング）のは専門家の判断で
  • 指令・指揮系統を通じて保健所と連携する（地域の計画による）
  • 曝露者リストの作成と追跡調査（接触者追跡）
  • ワクチン・抗生物質の予防投与（専門機関指示）
  • 廃棄物・遺体の特殊管理（バイオハザード袋）

  • 衣服除去で約80%の汚染を除去できる
🚨 対応・治療
  • 安定ヨウ素剤：放射性ヨウ素が甲状腺に取り込まれるのを防ぐだけ。国・自治体の指示で服用。目安は曝露の24時間前〜2時間後で、遅れるほど効果が落ちる。避難・屋内退避の代わりにはならない
  • ARS（急性放射線症候群）：被ばくから早い時間の嘔吐は、高線量被ばくを疑う手がかり（嘔吐の時刻を記録して伝える）
  • 皮膚の紅斑・脱毛は局所の放射線障害のこともある。出た時刻と範囲を記録し、ARSは被ばく状況・血液検査と合わせて評価
  • 医療機関でリンパ球数を早くから繰り返し測る（被ばく時刻を伝える）
  • 連絡は指令・指揮系統を通じて、地域の計画に沿って行う
  • 被ばくしただけの人から、ほかの人が汚染されることはない。命に関わるけがの処置を優先する
NE
Nuclear / Explosive — 核・爆発物
核爆発・爆発物（IED）・テロ・建物崩壊を伴う爆発
💥 爆傷（Blast Injury）の分類
  • 一次爆傷：爆風（blast wave）→ 鼓膜穿孔・肺挫傷・腸管損傷（外見上わかりにくい）
  • 二次爆傷：飛散物による刺傷・切創・眼球損傷
  • 三次爆傷：吹き飛ばされることによる鈍的外傷・骨折
  • 四次爆傷：熱傷・有毒ガス・建物崩壊による圧挫
  • 複合損傷が多い → 体表の傷に惑わされず全身を評価
🚨 対応手順
  • 二次爆発リスクに注意：現場に安易に近づかない
  • 爆発物処理班（EOD）確認後に救助活動開始
  • フラッシュバーン（熱線熱傷）・眼球損傷の評価
  • 核爆発：EMP（電磁パルス）による通信・医療機器障害に備える
  • 核爆発の場合：まず近くの頑丈な建物や地下に退避し、情報と指示を待ってから避難する
  • 警察・自衛隊などの関係機関と連携する
🏷
CBRNE 災害トリアージの修正
汚染環境下では優先順位・搬送判断の考え方が変わる
📌 通常との主な違い
  • 「救命可能性」に加え汚染状況・除染完了の有無が判断軸に加わる
  • 重症者は最低限の除染で搬送する場合がある。搬送先に事前連絡する
  • 汚染タグ（赤/黄/緑/黒 × 汚染あり/なし）を組み合わせて管理
🏷 汚染タグの運用
赤＋汚染 除染を最優先（脱衣など最低限）。必要な救命処置は防護して並行
黄＋汚染 除染ライン → 処置エリアへ順次移動
緑＋汚染 歩行除染（自己除染）ラインへ誘導
黒＋汚染 死亡者は汚染遺体として管理。生存している救命困難者は再評価と苦痛を和らげる対応
⚗️ 化学剤特有の修正
  • 神経剤の大量曝露 → けいれん・無呼吸でも回復の可能性あり（黒タグを急がない）。防護下で気道確保・補助換気・吸引を除染と並行し、医療者のアトロピン・PAM投与につなぐ
  • 歩行可能でも縮瞳・流涎があれば「黄」以上に変更
  • 症状なしでも曝露確認者は「緑」として経過観察
  • びらん剤：受傷後数時間で症状悪化（遅発性）→ 再トリアージ必須
☢️ 放射線特有の修正（ARS）
  • 早い時間の嘔吐は高線量被ばくの手がかり（時刻を記録）
  • 外見が正常でも高線量の被ばくが疑われる人は、専門家に相談して経過を見る
  • 外傷＋放射線の複合損傷は両方を同時評価
🚿
除染ラインの設置と運用
ウォームゾーン内に設置。方法は物質と状態で選ぶ。
① 脱衣・拭き取り（まず行う）
  • 腐食性の物質が皮膚や眼に付いたときは、すぐに水で洗う（脱衣を待たない）。水と反応する物質・粉体は物質ごとの手順に従う
  • 衣服・装備の除去で約80%の汚染を除去
  • 除去した衣服はビニール袋に密封して保管
  • 皮膚の粉塵・液滴はタオルや布で拭き取る（こすらない）
  • 液体や腐食性の物質が付いているときなどは、水による除染へ
② 水による除染（必要なときに）
  • 流水で全身を洗う（時間と方法は物質で決める）
  • 眼に付いたときは眼を洗う。口や鼻に水を流し込まない
  • 保温とプライバシーに配慮する
  • 歩行可能者：自己除染ライン（シャワー型）
  • 歩行不能者：担架・ストレッチャー除染ライン
  • 除染廃液の流出防止措置（土嚢・シート）が必要
🏷 除染完了の確認と搬送
  • 除染完了後に「除染済タグ／リストバンド」を装着
  • 搬送先には原因物質・行った除染・残っている汚染の可能性を事前に伝える
  • 再汚染防止のため清潔毛布・タオルで体を保護してから搬送
🗺 ゾーニング（除染配置）
ホット：汚染源の周り。防護した専門の隊だけが入る
ウォーム：除染ライン設置エリア
コールド：除染完了者・指揮所・救護所
🦺
PPE レベル早見表
状況に応じた適切な防護具の選択が二次被害防止の鍵
Level A
最高レベル（皮膚・呼吸器・眼を最大限に保護）
化学剤ホットゾーン内での救助・サンプリング
全身封入型化学防護服（SCBA内蔵）＋化学防護手袋・ブーツ
Level B
呼吸器：最高 / 皮膚：中程度
呼吸器の保護が最も必要で、皮膚への危険は比較的低いとき
化学防護服（非封入型）＋ SCBA ＋ 防護手袋・ブーツ
Level C
呼吸器：中程度 / 皮膚：中程度
物質と濃度が分かっていて、合う吸収缶を選べるとき
防護服 ＋ 物質に合った吸収缶つきの防護マスク（またはPAPR）＋ 防護手袋
吸収缶式マスク・PAPRは酸素を送らない。酸素濃度が十分で、濃度が使用限界内のときだけ使う。N95は粒子用で、ガス・蒸気は防げない
Level D
最低限（通常作業服レベル）
汚染なし確認済みコールドゾーン・指揮所
標準的な救急隊装備 ＋ サージカルマスク ＋ 手袋
このアプリの基準について
START法は国内で広く使われる修正START法、PAT法の数値は国内の消防で使われている一例です。除染・防護・安定ヨウ素剤は、消防庁・厚生労働省の化学災害の資料と原子力規制委員会の情報をもとにしています。地域の多数傷病者対応の要綱・プロトコールがある場合は、そちらを優先してください。（2026年11月 見直し）
